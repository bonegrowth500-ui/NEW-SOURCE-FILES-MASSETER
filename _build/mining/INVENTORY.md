**Source key (internal only; the blueprint never names either source):**
- **S+** = `sources/S_Tier_YouTube_Mastery.txt`. Locations are Part.section (e.g. S+ §2.3 = Part 2, section 3; S+ 7.4 = Part 7, section 4; "FM" = front matter).
- **BP** = `sources/The_20_Module_Blueprint.md`. Locations are module-by-order and section (e.g. BP M17 §5.3). KT = key takeaways. L2/L3 = audience Layer 2/3 in M2. F1–F15 = the M5 hook formulas.
**Tags:** EXTEND = core is valuable but must be deepened or modified · REUSE = valid as-is (native rename allowed) · RETIRE = conflicts with SPEC, STANDARD hard lines or exclusions, or too basic for an advanced sequel.
**Merge conventions:** a row that cites both S+ and BP is a cross-source merge; the "What it is" cell states how each source frames it when they differ. Where slices tagged the same concept differently, the Reasoning cell opens with **Tag call:** and explains the decision. All tag calls are also listed in §5.
**Theme placement:** each merged row sits in one theme only (the one where it will do most work); cross-references are noted in the reasoning.
**Reminder:** numbers are only indexed here; values, contradictions and verdicts live in `NUMBERS.md`. Source disagreements are framed in `CONFLICTS.md`. Missing material is in `GAPS.md`.
