# LEDGER — Canonical numbers & ranges

Every range used in any module must match this ledger (or the ledger is updated here first, with reasoning). Modules present these as **ranges with context** (what moves them up/down), never as single points, never cited.

**Status key.** **EV** = evidence-based (tag S/M/W) · **PL** = planning assumption (derived or estimated; the operator's own data replaces it) · **RULE** = a policy/design number we set.
**Denominators.** YouTube ratios per 1,000 *engaged* views; email per *delivered*; sales per *lead cohort*; profit per *operator hour*.

## E. Persuasion effect sizes (for calibrated explanation only)

| Mechanism | Size | Note | Status |
|---|---|---|---|
| Self-efficacy change → behavior | Largest tested belief lever (d≈0.47) | vs attitude ≈0.38, norms ≈0.36 | EV (S) |

| Correction backfire | Essentially none; effects small and fade | Repetition needed | EV (S) |
